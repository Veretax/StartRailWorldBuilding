Start Rail Learning & Manifestation Extractor

Purpose
Review Start Rail text logs and preserve reviewable learning and demonstrated manifestations as discoverable Drive records.

Invocation
Run the Start Rail Learning & Manifestation Extractor on these text logs.

Core rules
Use only what the source logs support. Preserve provenance. Do not invent textbook contents or table-of-contents entries. Keep explicit facts separate from interpretation. A mentioned book is not evidence of its contents. Character theorizing is not a demonstrated ability. Merge repeated manifestations into existing records instead of creating contradictions.

Reviewable Learning naming
CL-{ClassName}-{Professor}-Topic
TB-{TextBookName}-{Author(s)}-Topic
Art-{ArticleName}-{Author(s)}-Topic
PAP-{PaperName}-{Author(s)}-Topic
Theory-{Publication or theory title}-{Author(s)}-Topic

For textbooks and articles, preserve only the exposed table of contents. Preserve direct excerpts when the log exposes them. Record source log and scene/date when available.

Manifestation capture
Record every demonstrated ability, spell, conceptual-energy exercise, authority invocation, artifact-assisted effect, passive effect, and meaningful variation. Record manifested by, observed manifestation, explicit mechanism, trigger/context, effects, limits/costs, whether taught/practiced/accidental, source, confidence, and related manifestations.

Confidence
Explicit: directly demonstrated or stated by an authoritative source in the scene.
Reported: described by another character or telemetry.
Theory: proposed interpretation or unverified mechanism.

Persistence rule
A run is not complete until intended Drive writes are verified by readback. If Drive blocks a write, say so explicitly and do not claim the artifact was saved.

Textbook source-preservation rule
A TB-* record is a source-preservation artifact, not a summary. When a log displays textbook wording, copy that wording verbatim and organize it by the exposed chapter/section. When a table of contents is displayed, copy the exposed table of contents verbatim. When the log only narratively describes what a book says, preserve that narration verbatim under a label such as SOURCE NARRATION ABOUT THE TEXT — VERBATIM, NOT A DIRECT BOOK QUOTE. When a book is only mentioned or returned in a catalog/search result, preserve only the exact exposed catalog line and explicitly state that no chapter text was exposed. Never rewrite a summary as though it were textbook prose. Never infer an unexposed chapter, author, table of contents, or passage from nearby material. Keep Timothy's notes, mnemonics, and interpretations in separately labeled sections so they cannot be confused with the source text.
Raw-log provenance rule
Treat StartRail / Logs / rawlogs as the preferred source-of-truth corpus for historical refinement and review. Every preserved verbatim block must carry its own nearby source reference naming the exact raw .txt file from which that block was taken. Do not rely only on a document-level provenance note when a record contains multiple excerpts or sections. Use a form such as: SOURCE RAW LOG: <exact filename>. If different sections came from different raw logs, label each section independently. When practical, also record the scene/date or surrounding context, but the exact raw .txt filename is mandatory for every verbatim section.



Mediated source-reading rule
A textbook, treatise, article, paper, archive record, or other reviewable source does not have to be read directly by Timothy to qualify for extraction. Preserve source content when another character explicitly reads it aloud, displays it, quotes it, highlights it, transcribes it, or states that they are extracting it from the named source.

Use these labels:
DIRECT SOURCE TEXT — wording is presented as the source's own text, quotation, displayed passage, page, chapter, table of contents, formula, heading, or inscription.
MEDIATED READING / EXTRACTION — another character is explicitly reading, highlighting, displaying, or extracting content from the named source. Preserve that wording verbatim and label it mediated unless the scene explicitly identifies a portion as a direct quotation.

PARAPHRASE / INTERPRETATION — a character explains, summarizes, analyzes, or applies what the source means without presenting the original wording. Preserve it only when useful and label it as interpretation; never convert it into source prose.
TITLE / MENTION ONLY — the source is named, recommended, cataloged, shelved, assigned, or referenced without substantive contents being exposed. Preserve only the title/metadata and do not infer contents.

The deciding question is not who read it but how the scene represents the wording and what provenance is explicit. Eve/Makina, Sophie, Aira, Ecula, Glacia, an instructor, archive system, datapad, narrator, or another character may expose reviewable material.

When a mediated reader explicitly quotes a sentence from the source, split the record: explanatory material remains MEDIATED READING / EXTRACTION, while the explicitly quoted sentence is DIRECT SOURCE TEXT. Every block still requires the exact raw-log filename beside it.


Reading-discussion capture rule
When a named textbook, treatise, paper, article, archive record, manuscript, or other source is being actively read or discussed, preserve the full contiguous discussion segment relevant to that source, not only prose that visually resembles a printed book.

Capture, in order:
DIRECT SOURCE TEXT — displayed or explicitly quoted source wording.
MEDIATED READING / EXTRACTION — wording spoken or surfaced by Eve/Makina or another reader who is explicitly extracting from the named source.
DISCUSSION / COMMENTARY — source-grounded conversation immediately interpreting, questioning, challenging, or applying that reading. Preserve speaker attribution and wording verbatim when useful for review.
TIMOTHY NOTES / SYNTHESIS — Timothy's own notes, questions, analogies, mnemonics, or conclusions, clearly separated from the source.
READING ENDS / CONTEXT SHIFTS — stop the source block when the scene clearly changes book/chapter, moves to a different task, begins unrelated social/operational discussion, or otherwise ceases engaging the source.

Do not discard useful dialogue merely because it does not look like textbook prose. If Eve says she is reading, extracting, highlighting, or quoting from a named text, capture that dialogue as mediated source material. If the following conversation remains anchored to that text, capture the commentary too. Do not continue indefinitely after the scene leaves the reading context.

Every preserved subsection must include SOURCE RAW LOG: <exact .txt filename>. If the source chapter/section is named, preserve that context. If the chapter changes, start a new labeled subsection even when the book remains the same.
