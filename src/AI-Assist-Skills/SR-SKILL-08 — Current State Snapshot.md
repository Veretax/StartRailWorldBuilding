SR-SKILL-08 — Current State Snapshot

PURPOSE
Answer “where are we right now?” without running a full historical continuity audit. Produce a compact, evidence-grounded snapshot of the latest confirmed playable state.

COMMAND
/SRStatus
Optional focus arguments may narrow the snapshot: scene, resources, people, packages, objectives, inventory, threats.

REQUIRED SNAPSHOT
- Last confirmed playable edge: the latest game-response-confirmed point from which play can safely continue.
- Current/last confirmed date and time when known.
- Location.
- Timothy condition/status.
- Mana current/max and CE current/max when established.
- Living Web / Golden Foundation / active packages and structural load when established.
- People physically present or immediately connected.
- Scene-relevant relationship state.
- Active orders, agreements, consent boundaries, or protection details.
- Immediate objective(s).
- Scene-relevant inventory/artifacts.
- Active threats or unresolved hazards.
- Known unknowns that could affect the next action.

PLAYABLE-EDGE RULE
Never resume from an assistant draft, OOC plan, hypothesis, rejected generator replay, or unposted proposal. The playable edge must be supported by played continuity/game response. If the exact edge is uncertain, say so and identify the competing candidates.

FRESHNESS RULE
Prefer the newest confirmed state, but do not let a newer contradictory UI panel silently overwrite stronger established continuity. Hand contradictions to SR-SKILL-02 and resources to SR-SKILL-03.

DISTINCTION FROM /SRSeed
/SRStatus is a factual current-state snapshot. /SRSeed is a portable new-session continuity package containing broader history, rules, relationships, unresolved threads, and anti-replay guardrails.

OUTPUT
Keep concise enough for immediate play. Explicitly label stale/unknown fields rather than guessing.

END SKILL
