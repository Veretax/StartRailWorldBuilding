# SR-ABIL-01 — Timothy Maddox Ability Taxonomy — Living Web and Conceptual

## Purpose
Top-level ability list separating Timothy's personal Living Web / conceptual capabilities from team engineering, procedures, hypotheses, and construct-derived behavior. Detailed mechanics remain in SR-WEB-06/07/08 and event files.

## Status Key
ESTABLISHED = source-demonstrated with observed result.
DEMONSTRATED ONCE = real result, insufficient repetition for mastery.
PROVISIONAL = real but unsafe/poorly bounded.
PROPOSED = designed, not yet established.
TEAM ENGINEERING = Timothy contributes materially but cannot claim solo execution.
PROTOCOL = skill/method, not a supernatural power.
NOT A SKILL = anomaly, interpretation, or derivative behavior.
