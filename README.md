# Start Rail Worldbuilding

Supplemental continuity and worldbuilding material for my Start Rail Academy roleplay.

This repository exists to hold material that is too large or structured for the game's comment system, including character definitions, magical systems, locations, mechanics, and continuity references.

## Structure

- `SideCharacters/` — Supporting characters available for organic encounters.
- `Characters/` — Major recurring character information.
- `Magic/` — Spells, magical theory, constructs, and experiments.
- `Locations/` — Important places and setting information.
- `Systems/` — Game mechanics, commands, terminology, and continuity rules.

## Design Principle

This repository supplements the roleplay rather than predetermining it.

Character relationships, discoveries, conflicts, and story outcomes should develop through play unless explicitly established as continuity.
